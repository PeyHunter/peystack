# Teach

1. Ask nothing. Guess the learner's level from the conversation.
2. Run `/how` on the subject. Run `/why` when the shape is surprising.
3. Teach in this order: the problem it solves, a mental model in one paragraph, one concrete walk-through with real `file:line`, the two or three things that trip people up, and a check question the reader can answer.
4. Plain words. One small diagram if it helps. No section the learner does not need.

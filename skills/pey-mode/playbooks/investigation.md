# Investigation

Read-only. The deliverable is a cited answer or a recommendation, not a change.

1. "How" questions run `/how`. Motivation questions also run `/why`.
2. Answer in sections: Overview, Key concepts, How it works, Where things live, Gotchas. Drop empty ones. A decision between options gets a tradeoffs table and a pick.
3. Cite `file:line` for each claim. Push back if the premise is wrong.

No PR. If the answer leads to a change, route to Bug fix or Feature.

**Reply:** the answer, your judgment with reasons.

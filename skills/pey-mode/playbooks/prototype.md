# Prototype

A throwaway instrument to decide something cheaply. Speed over polish. The real build follows Feature.

1. Name the decision. No decision means no prototype.
2. If the design space is open, gather a few references and let the user pick directions. Skip when set.
3. Build in a scratch dir outside production source. Visual: plain HTML/CSS/JS with CDN deps. Behavioral: the smallest script that exercises the question.
4. Put variants behind one switcher, each labeled.
5. Observe each variant: screenshot it, or log the timing or output.
6. Present variants, evidence, tradeoffs, a pick.

**Reply:** variants, evidence, pick, scratch path, and a plain note that it is throwaway.
